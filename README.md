# YouTube Automation Agency Website

Official high-converting luxury website for **Usama Khursheed's YouTube Automation Agency**.

## 🚀 Features & Components
- **Executive Hero Orbital Engine**: Interactive 3D flip card with Option 2 Tachometer Gear Engine & 1:1 Math-Coupled Speedometer physics ($5,280 start price).
- **24/7 Animated Production System Visualizer**: Interactive 4-stage pipeline (Scriptwriting, Voiceover, 4K Editing, CTR Thumbnails).
- **Live Studio Simulator**: Interactive video preview player.
- **Founder Authority & Story**: Usama Khursheed's channel portfolio & growth track record.
- **90-Day Monetization Guarantee**: Zero-risk guarantee banner.
- **Done-For-You Services Showcase**: Transparent service breakdown & package comparison.
- **Interactive Contact & Strategy Call Modal**: Lead capture modal with live booking integration.

## 🛠️ Tech Stack
- **Framework**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Deployment**: Vercel / Hostinger Static Build

## 🏃 Local Development
```bash
npm install
npm run dev
```

## 📦 Production Build
```bash
npm run build
```
Output is generated in `dist/`.
